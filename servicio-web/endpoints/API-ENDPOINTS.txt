PROYECTO   : InventaPlus - Sistema de gestion de equipos

--------------------------------------------------------------------------------
1. CONFIGURACION
--------------------------------------------------------------------------------

Base URL (servidor local de desarrollo)   : http://127.0.0.1:8090
Punto de entrada de la API                 : http://127.0.0.1:8090/api.php
Formato de las peticiones y respuestas     : JSON (application/json; charset=utf-8)
Formato de las credenciales en Postman    : Body > raw > JSON
Variable de entorno                        : {{base_url}} = http://127.0.0.1:8090

Comando para levantar la API:
    php -S 127.0.0.1:8090 -t servicio-web

--------------------------------------------------------------------------------
4. CODIGOS DE ESTADO UTILIZADOS
--------------------------------------------------------------------------------

| Codigo | Significado en la API                                        |
|--------|--------------------------------------------------------------|
| 200    | La operacion se realizo correctamente                         |
| 201    | El recurso fue creado correctamente                            |
| 400    | Faltan datos o un valor no cumple las validaciones            |
| 401    | Credenciales incorrectas                                       |
| 404    | El recurso o la ruta solicitada no existe                     |
| 405    | El metodo HTTP no esta permitido para ese servicio             |
| 409    | Conflicto: dato duplicado o registro con relaciones asociadas  |
| 500    | Error interno del servicio                                     |
