NOTAS
- El proyecto se creo con Git (control de versiones local) y se publico
  en GitHub como repositorio remoto.
- Para ejecutar la API: php -S 127.0.0.1:8090 -t servicio-web
- Base de datos del proyecto: inventario (database/inventario.sql)
- Las credenciales del administrador no se publican en el repositorio.
- La coleccion de Postman usa las variables {{usuario_admin}} y {{clave_admin}};
  la clave se configura localmente en el entorno de Postman.
- Resultado de la ejecucion completa: 39/39 peticiones y 139/139 aserciones
  correctas, sin fallos.
- Despues de las pruebas se ejecuta:
  mysql -u root < servicio-web/limpiar-datos-prueba.sql
